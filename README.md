# CUNY Cataloging Decision Tree

An interactive decision tree that helps CUNY library staff figure out where a record belongs and what to do next. Answer a few questions about what you're working on, and the tool walks you through the right steps.

**Live:** [ols.cuny.edu/alma/cataloging-decision-tree](https://ols.cuny.edu/alma/cataloging-decision-tree/)

## What it does

- Walks through a series of questions based on what you're trying to do (add a title, edit an existing record, or quick-catalog for a patron checkout)
- Covers physical items, electronic resources (collections and standalone portfolios), and record editing in the IZ and NZ
- Recommends a specific workflow with step-by-step instructions
- Includes a glossary of Alma cataloging terms

## How it works

A single self-contained HTML file with vanilla JavaScript — no build step, no dependencies. The decision tree data and all styles are inline. The page can also be embedded as an Alma widget (it automatically hides the header and footer when loaded inside an iframe).
