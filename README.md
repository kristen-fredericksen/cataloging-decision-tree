# CUNY Cataloging Decision Tree

An interactive decision tree that helps CUNY library staff figure out where a record belongs and what to do next. Covers physical items, electronic resources, editing existing records, and quick cataloging for patron checkouts.

Built as a single self-contained HTML file using the CUNY Library Services design system.

**Live:** [ols.cuny.edu/alma/cataloging-decision-tree](https://ols.cuny.edu/alma/cataloging-decision-tree/)
